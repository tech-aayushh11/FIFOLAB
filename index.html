Why does Belady's Anomaly happen in FIFO?

In stack-based page replacement algorithms (such as LRU or Optimal), the set of pages in memory for k frames is always a strict subset of the set of pages for k+1 frames (known as the Stack Inclusion Property). FIFO does not possess this stack property.

In this example, at reference 5, having 4 frames displaced page 1 earlier than the 3-frame allocation did. Consequently, subsequent references to 1, 2, 3, and 4 generate unexpected cascading faults, leading to 10 faults with 4 frames compared to only 9 faults with 3 frames!

How FIFO Works — Engineering Guide

Fundamental concepts, replacement mechanics, complexity analysis, and college viva questions.

01

Page Replacement Concept

When a process requests a virtual memory page not currently resident in physical RAM, the CPU generates a Page Fault interrupt. If all allocated frame slots are full, an existing resident page must be chosen for eviction (replacement) to make room for the incoming page.

02

FIFO Selection Rule

First-In, First-Out associates each resident page with the timestamp or sequence number when it entered memory. When eviction is required, the oldest loaded page (the one at the front of the FIFO queue) is selected. Crucially, hits do not refresh a page's FIFO age!

03

Algorithm Pseudocode

1. Initialize empty frame slots [null ... null]
2. Initialize empty FIFO queue Q = []
3. For each referenced page P:
     If P is in frames:
       Record HIT; (Q remains unchanged)
     Else:
       Record PAGE FAULT;
       If free slot exists:
         Load P into free slot; Enqueue(Q, P);
       Else:
         Evicted = Dequeue(Q);
         Replace Evicted with P in slot;
         Enqueue(Q, P);
04

Complexity Analysis

  • Straightforward Scan: Scanning f frames per reference takes O(n × f) time, where n is reference count and f is frame count.
  • Optimized Structure: Using a Hash Set + Doubly-Linked Queue achieves O(1) amortized check and eviction per step (O(n) total).
  • Space Complexity: Requires O(f) auxiliary memory for resident frame storage.

Common Engineering Viva Questions & Model Answers

Why does a hit not change the queue order in FIFO?
In FIFO, eviction priority depends strictly on arrival time, not access recency. If you were to move a hit page to the rear of the queue, the algorithm would become LRU (Least Recently Used) instead of FIFO.
What is Belady's Anomaly and which algorithms suffer from it?
Belady's Anomaly is when increasing the number of physical memory frames leads to an increase in the number of page faults. Algorithms that do not obey the stack inclusion property (like FIFO and Second Chance) can exhibit Belady's anomaly. Stack algorithms (like LRU and Optimal) never suffer from it.
What are the trade-offs of FIFO compared to LRU and Optimal?
Advantages: Low computational overhead, extremely simple to implement with a circular buffer or queue, no complex hardware access-bit tracking required.
Disadvantages: Poor hit ratio for programs with frequently accessed legacy pages (e.g. initialization loops), susceptible to Belady's anomaly, and significantly outperformed by LRU and Clock replacement.
